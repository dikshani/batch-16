# RCA: My Profile QA API – 502 Bad Gateway

**Date:** 9 October 2026  
**Environment:** QA  
**Service:** `fastapi_myprofile`  
**Endpoint:** `https://mp-qa-api.venturasecurities.com/ssov5/myprofile/v1/user/mtf/status`

## 1. Incident Summary

The My Profile FastAPI service was failing to start correctly. NGINX was configured to forward requests to the FastAPI application on `127.0.0.1:8081`, but the application was not listening on that port. This could cause requests routed through that upstream to return `502 Bad Gateway`.

## 2. Root Cause

The systemd service did not define the `ENV` environment variable.

In `src/ec2/api/config.py`, the application selects its configuration using:

```python
CONFIG = CONFIG_ALL_ENV.get(os.getenv("ENV"))
```

Because `ENV` was missing, `os.getenv("ENV")` returned no value and `CONFIG` became `None`. The database module then attempted to access a key from `CONFIG`, causing initialization to fail:

```python
SSO_SECRET_ARN = CONFIG['VENTURA1_MP_PROXY_DB_SECRET_ARN_v5']
```

As a result, Gunicorn workers failed during startup and port `8081` was not listening.

## 3. Fix Applied

A systemd drop-in override was created at:

`/etc/systemd/system/fastapi_myprofile.service.d/override.conf`

The override contains:

```ini
[Service]
Environment="ENV=qa"
```

Then the service was reloaded and restarted:

```bash
sudo systemctl daemon-reload
sudo systemctl restart fastapi_myprofile
```

## 4. Verification Results

After applying the override:

- `fastapi_myprofile` showed as `active (running)`.
- Gunicorn started successfully with 9 workers.
- Port `127.0.0.1:8081` was listening.
- Application startup completed for all 9 workers.
- The local unauthenticated request returned HTTP `400 Bad Request` with a generic error message.
- The public endpoint returned HTTP `401` with `{"session_expired":false,"message":"No ID found"}`. The response included `x-powered-by: Express`, indicating that this response was generated by an Express layer. This does **not** confirm that the request reached FastAPI.

## 5. Current Status

**Service startup issue: resolved.** The missing `ENV=qa` setting was added and Gunicorn is running.

**End-to-end API issue: not yet confirmed resolved.** The public endpoint's HTTP `401` response and the local endpoint's HTTP `400` response still require investigation. NGINX upstream routing and the correct authentication/request headers have not yet been verified.

## 7. Short RCA for Sharing

The My Profile QA API encountered a 502 Bad Gateway condition because the FastAPI systemd service did not have the required `ENV` environment variable. Consequently, application configuration was not loaded, causing Gunicorn workers to fail during startup and leaving port 8081 unavailable. The issue was addressed by adding `Environment="ENV=qa"` through a systemd drop-in override and restarting the service. Gunicorn is now running with 9 workers and port 8081 is listening. End-to-end API functionality is still under verification because the local request returns HTTP 400 and the public endpoint returns HTTP 401 with “No ID found.”
